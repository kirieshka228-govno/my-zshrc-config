# My .zshrc config

Мой очень простой конфиг для .zshrc

## Что в нём:

1. Oh my Zsh (Нужно ОБЯЗАТЕЛЬНО установить)
2. Powerlevel10k тема
3. Alias-ы на cd, ls и rgi
4. Плагины git, sudo, zsh-autosuggestions, zsh-syntax-highlighting (Нужно ОБЯЗАТЕЛЬНО установить)

## Установка

### Для иконок в eza (ls) нужно установить Nerd Font и поставить шрифт в конфиге терминала

1. Пропиши в терминале команду ``git clone https://github.com/kirieshka228-govno/my-zshrc-config.git``
2. Зайди в папку my-zshrc-config
3. Пропиши ``cp .zshrc ~``
4. Перейди в директорию ~
5. Пропиши ``source .zshrc`` или перезайди в терминал
6. Готово!
